# 极客风格模板

> **目标读者**：开发者 / 技术管理者 / 早期采用者
> **平台特点**：掘金 / 少数派 / 知乎 / V2EX / 个人博客
> **长度**：1500-4000 字（含代码块）
> **调性**：技术准确 / 客观中立 / 工具有对比 / 有数据支撑

## 标题套路（6 个模板）

| 类型 | 模板 | 例 |
|------|------|----|
| 工具盘点 | `<时间>+<领域>+<数量>+<筛选标准>` | 2026 年 GitHub 上最值得引入 AI 管理现场的 10 个开源 Agent |
| 工具评测 | `<工具名>+<核心特性>+<适用场景>` | n8n：把 50 个 SaaS 用一条流程串起来 |
| 对比评测 | `<A> vs <B>：<结论>` | LangChain vs LangGraph：状态管理场景怎么选 |
| 教程 | `<任务>+用<工具>+<效果>` | 用 RAGFlow 搭企业内部知识库：7 天实测 |
| 趋势 | `<时间>+<趋势>+<数据>` | WEF 数据：97% HR 已在用 AI，但只有 19% 见效 |
| 观点 | `<争议话题>：<我的观点>` | 自动驾驶式 AI Agent：是真革命还是过度炒作 |

**通用规则**：
- 标题诚实、不夸张（"实测"、"对比"、"实测数据"增加可信度）
- 必要时带版本号或时间锚点（"2026.08"、"v2.0"）
- 不用感叹号、不用 emoji（除非平台风格允许）

## 开头套路（3 段引入）

### A. 问题引入
```
过去三个月，我做了一件事：把 GitHub 上 star 数排在前 50 的 Agent
框架、Agent 平台、Agent 工具，逐个问自己三个问题：

1. 一个非工程师的部门负责人，今天打开它，能不能在一个下午搭出
   一个能用的东西？
2. 它能不能接到云滇已经有的系统——飞书、企微、钉钉、Notion、
   企业知识库、CRM？
3. 六个月后，它是会变成公司里的「真家伙」，还是被默默关掉？
```

### B. 数据引入
```
WEF（世界经济论坛）2026 年最新数据：97% 的 HR 领导者认为，
AI 时代最值钱的不是技术能力。

但同样这份数据显示，只有 19% 的企业真的把 AI 用出了效果。

剩下 81% 卡在哪里？我花了三个月，把 30 家企业跑了一遍。
```

### C. 经验引入
```
我在两家千人企业做过 AI 转型咨询，最常被问的问题是：

"林老师，我们部门该不该上一个 Agent？"

我的回答永远是反问："你们的第一件值得 AI 化的工作，到底是什么？"

如果你答不上来，请继续往下看。
```

## 结构模板（5 段式）

```
【第 1 段】开头钩子（上面 3 个模板之一），200-400 字

【第 2 段】标准设定
   "本文按以下 3 条标准筛：xxx / yyy / zzz"
   列出可验证的筛选维度

【第 3 段】逐项评测（核心 1500-2500 字）
   每个工具/Agent 1 个 subsection：
   - 一句话定位
   - 核心能力（技术细节）
   - 适用场景（具体业务）
   - 不适用场景（诚实说）
   - 实测数据（如 star 数、PR 数、issue 响应时间）
   - 配 1-2 张截图或代码块

【第 4 段】横向对比表（必须）
   | 维度 | 工具 A | 工具 B | 工具 C |
   |------|--------|--------|--------|
   | 上手难度 | 低 | 中 | 高 |
   | 中文支持 | 优 | 良 | 良 |
   | ... |

【第 5 段】落地建议 + 风险提示
   - "如果你只上一款，先上 X"
   - "不建议 Y 场景用 Z"
   - 30 天落地路线图（可选）
```

## Emoji 用法（**极简**）

- 总量：0-2 个/篇（甚至 0）
- 位置：仅在子标题或代码注释
- 偏好：📌💡⚡（极克制）
- 避免：🔥💥✨（过度活泼）

## 代码块

- 必要场景：工具对比、配置示例、API 调用
- 格式：标准 markdown 三引号 + 语言标记
- 注释清晰：每段代码前说明"做什么、为什么、怎么用"

## 长度

- 目标：2500-3500 字
- 下限：1500 字（信息密度要够）
- 上限：5000 字（再长就拆成系列）

## 客观性要求（关键）

- **不夸大**：不用"完美"、"无懈可击"、"秒杀"
- **诚实说不足**：每个工具列"不适用场景"
- **数据来源**：star 数、PR 数等数据必须标注来源和时间
- **个人体验**：标注"主观判断"和"实测数据"的边界

## 禁用词

| 类型 | 词 |
|------|-----|
| 营销 | 完美、颠覆、革命、秒杀、碾压 |
| 主观 | 我觉得、可能、或许（用数据替代） |
| 模板化 | 综上所述、值得注意的是、首先...其次...最后 |
| 假大空 | 重新定义、赋能、抓手、闭环 |

## 推荐配图

- 工具架构图（自己画的，不是网上抄的）
- 代码块截图（用真代码，不用伪代码）
- 对比表（必须原创数据）
- 实测场景截图
- 不用：装饰性 emoji 图、网络梗图
