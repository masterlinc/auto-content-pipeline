# 公众号风格模板

> **目标读者**：18-45 岁中国用户，移动端阅读为主
> **平台特点**：长文 / 收藏率高 / 转发靠"值得收藏"
> **长度**：1500-3000 字
> **调性**：信息密度高 + 故事化开头 + 强观点 + 行动号召

## 标题套路（8 个模板）

| 类型 | 模板 | 例 |
|------|------|----|
| 数字 | `<数字>个<方法/真相>，<人群>必看` | 5 个 AI 工具，让你的周报效率翻倍 |
| 反常识 | `<普遍认知>？<反直觉结论>` | 加班不是努力，是效率问题 |
| 痛点 | `<人群>+<痛点>+<解决方案>` | 中层管理者最该外包的不是执行，是会议 |
| 故事 | `<人物>+<动作>+<结果>` | 我帮一个 30 人公司做了 3 个月 AI 改造，结果…… |
| 对比 | `<A> vs <B>：<谁赢>+<为什么>` | 流程自动化 vs AI Agent：谁才是 2026 的效率之王 |
| 趋势 | `<时间>+<趋势>+<怎么应对>` | 2026 年 HR 报告：97% 的人已经在用 AI |
| 盘点 | `<时间>+<领域>+<数量>+<筛选标准>` | 2026 年 GitHub 上最值得引入的 10 个开源 Agent |
| 警示 | `<错误做法>？<正确做法>` | 别再让 AI 写周报了，正确用法是这样 |

**通用规则**：
- 18-26 字最佳，移动端单行显示完整
- 标题里出现数字提升打开率 23%
- 避免"震惊！""速看！""99% 的人"等过时套路

## 开头套路（4 个模板）

### A. 故事化
```
三个月前，我陪一位校长做了一场 AI 转型咨询。

他的周报是这样写的：周一开了 3 个会，周二对接了 5 个供应商……

我看完只问了一句：这些事，你做的和下属做的，结果真的不一样吗？
```

### B. 反常识
```
大多数管理者以为，"忙"就是"努力"。

但我看了 200 份管理日志后，发现一个反直觉的事实：

越是高层的领导，"忙"的占比越低。"判断 + 拍板"的占比越高。
```

### C. 数据冲击
```
97% 的 HR 领导者说，AI 时代最值钱的不是技术能力。

但只有 19% 的企业，真的把 AI 用出效果了。

为什么差距这么大？
```

### D. 提问开场
```
如果让你这一周的工作里，砍掉 50% 的会议时间，你会觉得：

A. 不可能，会议就是管理本身
B. 可以，但要重新设计议程
C. 必须砍掉，我已经在想怎么做了

选 A 的人请继续看。
```

## 结构模板（5 段式）

```
第 1 段（开篇 100-200 字）：用上面 4 个套路之一引入
第 2 段（核心观点 300-500 字）：明确给出"我的判断"
第 3 段（论据 800-1500 字）：
   - 案例 1（真实场景）
   - 案例 2（数据/研究）
   - 案例 3（反面教材）
第 4 段（行动建议 300-500 字）：3-5 条具体怎么做
第 5 段（结尾 + CTA 100-200 字）：
   - 一句话金句
   - 转发引导（"转发给身边的中层管理者"）
   - 关注引导（"关注我，下一篇讲 X"）
```

## Emoji 用法

- 总量：4-8 个/篇
- 位置：**仅用于分段标记**（不是装饰）
- 偏好：📌💡⚡🔥📍❗（克制、专业）
- 避免：🌟✨🎉（过度活泼）

## 禁用词

| 类型 | 词 |
|------|-----|
| 标题党 | 震惊！、速看！、99% 的人、不转不是…… |
| 油腻 | 小编、我们一起来看、大家好、今天给大家带来 |
| 鸡汤 | 努力就会成功、相信坚持的力量 |
| 假大空 | 颠覆、革命、重新定义、赋能、抓手 |
| 官腔 | 高度重视、深入研究、积极推进、稳步开展 |

## 长度

- 目标：2000-2500 字
- 下限：1500 字（信息密度不够就加案例）
- 上限：3500 字（移动端耐心极限）

## 排版

- 每段 3-5 行（移动端单屏 5-8 段）
- 重点加粗（不超 3 处/篇）
- 长段拆小段，必要时用引用块
- 配图：3-5 张（公众号配图率与完读率正相关）
