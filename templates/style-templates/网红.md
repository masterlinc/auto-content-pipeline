# 网红风格模板

> **目标读者**：18-30 岁，年轻女性为主，移动端碎片化阅读
> **平台特点**：小红书 / 抖音图文 / 即刻
> **长度**：300-700 字（图配文）
> **调性**：个人化视角 / 情绪饱满 / 一句话金句 / emoji 多

## 标题套路（10 个模板）

| 类型 | 模板 | 例 |
|------|------|----|
| 数字 | `<数字>个<东西>+<人群>` | 5 个 AI 神器，打工人必备 |
| 标签 | `#<人群>+<痛点>+<解决>` | #打工人 #AI神器 #效率翻倍 |
| 痛点 | `<痛点>+？+<解决方案>` | 周报写到崩溃？这个 AI 救我命 |
| 工具 | `<工具名>+<核心卖点>` | Notion AI：把 5 小时笔记压成 30 分钟 |
| 对比 | `<旧方法>+<新方法>` | 手写周报 vs AI 周报，差距太真实 |
| 惊喜 | `<发现>+<情绪>` | 救命！这个 AI 把我一周的活 30 分钟干完了 |
| 警示 | `<错误>+<正确>` | 别再用 ChatGPT 写周报了！正确用法 |
| 剧情 | `<时间>+<转折>+<结果>` | 用了 3 个月 AI 后，我被升职了 |
| 提问 | `<问题>？<悬念>` | 管理者 70% 的时间都在干嘛？答案扎心 |
| 数字震撼 | `<数字>倍+<结果>` | 效率 10 倍！我靠 AI 把周报从 3 小时压到 20 分钟 |

## 开头套路（3 句话钩子）

```
🔥 【痛点钩子】
救命！打工人都这样吧——周报写到凌晨两点...

💡 【工具钩子】
今天安利一个我用了 3 个月的 AI 神器：<工具名>。

✨ 【对比钩子】
我以前每周要花 5 小时写周报，现在 20 分钟搞定。
```

**规则**：
- 第一句必须抓人（痛点/惊喜/对比）
- 第二句引入主题
- 第三句预告价值

## 结构模板（5 段式）

```
【第 1 段】3 句话钩子（痛点/工具/对比）

【第 2 段】为什么好用（核心 1 个点，不超过 3 个 bullet）
📍 关键点：
• 真实场景描述
• 一句话金句
• 对比数据

【第 3 段】怎么用（3 步操作）
💡 三步上手：
1. 第一步（截图演示）
2. 第二步
3. 第三步

【第 4 段】我的真实体验（情绪 + 数据）
✨ 用了 3 个月，我的感受是：
- 情绪词 1
- 情绪词 2
- 具体数据

【第 5 段】话题标签 + CTA
#打工人 #AI工具 #效率神器 #周报神器
姐妹们冲！评论区告诉我你的体验 ❤️
```

## Emoji 用法（**重度**）

- 总量：10-20 个/篇（不嫌多）
- 偏好：✨💖🔥💕💡📍🎯⚡💥🎀💗💓💝💘
- 每段开头一个 emoji
- bullet 前用 emoji
- 重点词前后用 emoji 包围

## 长度

- 目标：400-600 字
- 下限：300 字（小红书短文也要够信息量）
- 上限：700 字（超过用户会划走）

## 一句话金句（必备）

每篇至少 1 条"传播金句"，格式：

```
> 打工不是忙，是没找到让 AI 干的事。
```

或

```
> 周报不是写给老板看的，是写给"未来的自己"看的。
```

## 禁用词（网红风格反而鼓励的）

| 鼓励 | 避免 |
|------|------|
| 救命、绝绝子、yyds、宝藏 | 震惊、99% 的人 |
| 姐妹、宝宝、家人们 | 小编、我们 |
| 真的、巨、超 | 高度重视、积极推进 |
| 冲！、盘它 | 综上所述、值得注意的是 |

## 视觉要求

- **封面图必须**：3:4、饱和度高、有大字标题
- **正文图**：3-6 张，建议截图 + 自拍风格
- 配色：明亮、糖果色系优先
