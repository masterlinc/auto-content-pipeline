# Dankoe 风格模板 — 单色调极简风

> **🚨 这是锁定版本。要改必须跟 linc 确认，agent 不自动改。**
>
> **来源**：参考 Dan Koe（@dankoe，X/Twitter 知名 one-person business 创作者）的视觉风格——
> 黑底 + 单色大字 + 大留白 + 强反差 + 一句话主张。

## 核心原则（5 条，缺一不可）

1. **黑底白字**（或反色，**绝不混色**）
2. **一个字也不要多余**（删到不能再删）
3. **一个画面只表达一个观点**
4. **大字号占画面 60-80%**
5. **留白 ≥ 30%**

## 配色（永远只用这 4 色）

```
背景：   #000000 纯黑（或 #FFFFFF 纯白）
文字：   #FFFFFF 纯白（或 #000000 纯黑）
强调：   #FF3B30 警示红（1 处，每篇不超过 1 处）
辅助：   #8E8E93 灰（次要信息）
```

❌ 禁止：渐变、阴影、3D、emoji 装饰图、暖色调、彩色背景

## 字体

- **主**：Helvetica Neue Bold / Inter Black / 思源黑体 Heavy
- **次**：同上 Medium（正文）
- **数字**：DIN Alternate Bold（视觉冲击）

字号：
- 标题：≥ 96px（封面）/ ≥ 48px（正文）
- 正文：≥ 24px
- 不出现小于 20px 的字

## 排版（4 个模板）

### 模板 A：全屏大字

```
┌────────────────────────────────┐
│                                │
│                                │
│     一个人就是一家公司。          │
│                                │
│                                │
└────────────────────────────────┘
```

适用：封面、首图、强观点

### 模板 B：左上锚点

```
┌────────────────────────┐
│ 不上班                │
│ 不是自由             │
│ 是选择               │
│                      │
│        [留白 60%]    │
│                      │
└────────────────────────┘
```

适用：观点对比、反常识

### 模板 C：极简分割

```
┌────────────────────────────────┐
│                                │
│       老板只需要做一件事            │
│                                │
│       ─────                     │
│                                │
│       招聘                      │
│                                │
└────────────────────────────────┘
```

适用：步骤、清单

### 模板 D：数字冲击

```
┌────────────────────────────────┐
│                                │
│         70%                    │
│                                │
│    是假装在管理                │
│                                │
└────────────────────────────────┘
```

适用：数据、洞察、震撼

## 文字内容规则

**每张图 1 句话，** 不超过 **20 字**。

**句式库**：
- "X 不是 Y，是 Z"
- "Y% 的人不知道 X"
- "X 不会 Y，但会 Z"
- "想 X，先 Y"
- "X + Y = Z"

❌ 禁用："震惊！""必看""99% 的人""家人们""宝子们"——所有 Dan Koe 不会用的词

## 正文章节图（inline）

每章只 1 张图（不放 3-6 张）：
- 截图风格：**纯色背景 + 大字**（**不是**配图风格）
- 字号比封面略小（≥ 64px）
- 占页面宽度 100%

## 封面（小红书 / 公众号 / 极客通用）

```
┌─────────────────────┐
│                     │
│   [标题 14-20 字]    │
│                     │
│   ─────             │
│   [副标题 / 数据]    │
│                     │
│              角落 logo│
└─────────────────────┘
```

- 角落 logo 必放（≤ 80×80px）
- 字号比封面更大、更突出
- 不放任何"配图"、"插画"

## 不做的事

- ❌ 用 emoji 当主视觉
- ❌ 用渐变、阴影、3D
- ❌ 用暖色（橙黄红系）做大面积背景
- ❌ 在 1 张图里说 2 个观点
- ❌ 放超过 30 字
- ❌ 用网络梗图、二次元图

## 跟其它模板的优先级

illustrate stage 选模板顺序：

1. **如果内容是"观点 / 强情绪 / 反常识"** → **dankoe.md**（默认）
2. 如果内容是"教程 / 工具盘点 / 实操" → 极客.md
3. 如果内容是"种草 / 体验 / 个人故事" → 网红.md
4. 如果内容是"长文深度 / 案例分析" → 公众号.md

> **默认规则**：除非 linc 在 frontmatter 指定 `style: <模板名>`，illustrate stage 默认走 dankoe。
