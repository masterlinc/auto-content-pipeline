## Part 1: 视觉风格（illustrate / cover 阶段）

### 配色（**只用 4 色**，黑/白为主，灰为辅，红为点睛）

```
背景：   #000000 纯黑（默认）或 #FFFFFF 纯白
文字：   #FFFFFF 纯白（或反色）
强调：   #FF3B30 警示红（**每篇最多 1 处**）
辅助：   #8E8E93 灰（次要信息/分割线）
```

❌ **禁用**：渐变、阴影、3D 效果、暖色系大面积背景、emoji 装饰图、彩色 logo

### 字体

- **主**：Helvetica Neue Bold / Inter Black / 思源黑体 Heavy（粗体）
- **次**：同上 Medium（正文）
- **数字**：DIN Alternate Bold（视觉冲击）
- **可选（学术感）**：EB Garamond / 思源宋体 Heavy（Dan Koe 长文用）

字号（**大是关键**）：
- 封面标题：≥ 96px
- 章节大字：≥ 64px
- 正文：≥ 24px
- ❌ 永不出现 < 20px 的字

### 排版（5 个模板）

#### 模板 A：全屏大字（最常用）
```
┌────────────────────────────────┐
│                                │
│                                │
│      一个人就是一家公司。          │
│                                │
│                                │
└────────────────────────────────┘
```
适用：封面、首图、强观点

#### 模板 B：左上锚点
```
┌────────────────────────┐
│ 不上班                │
│ 不是自由             │
│ 是选择               │
│                      │
│        [留白 60%]    │
│                      │
└────────────────────────┘
```
适用：观点对比、反常识

#### 模板 C：极简分割
```
┌────────────────────────────────┐
│                                │
│       老板只需要做一件事            │
│                                │
│       ─────                     │
│                                │
│       招聘                      │
│                                │
└────────────────────────────────┘
```
适用：步骤、清单

#### 模板 D：数字冲击
```
┌────────────────────────────────┐
│                                │
│         70%                    │
│                                │
│    是假装在管理                │
│                                │
└────────────────────────────────┘
```
适用：数据、洞察、震撼

#### 模板 E：宽屏 16:9 横幅（学术 / 长文封面）
```
┌────────────────────────────────────────┐
│                                        │
│  [小字·副标题]                          │
│  ──────────                             │
│  [大字·主标题]                          │
│  ──────────                             │
│  [超大字·数据/主张]                     │
│                                        │
└────────────────────────────────────────┘
```
适用：公众号文章封面、极客类封面

### 文字内容规则

**每张图 1 句话，** 不超过 **20 字**（数字模板可放宽到 30 字）。

**句式库**（来自 Dan Koe 公开内容）：
- `X 不是 Y，是 Z`
- `Y% 的人不知道 X`
- `X 不会 Y，但会 Z`
- `想 X，先 Y`
- `X + Y = Z`
- **`Stop being [old identity]. Become [new identity].`**（**身份转换钩子**，Dan Koe 招牌）
- **`The [modern problem]. The [philosophical reframe]. The [tactical fix].`**（**3-beat 结构**）
- `My [system/workflow]: 1. [Specific action] 2. ...`（**流程揭示**）

❌ 禁用："震惊！""必看""99% 的人""家人们""宝子们""绝绝子"——所有 Dan Koe 不会用的词

### 尺寸

| 平台 | 比例 | 尺寸 |
|------|------|------|
| 小红书封面 | 3:4 | 1242×1660 |
| 公众号封面 | 16:9 | 1200×675 |
| 极客 / Twitter 文章封面 | 16:9 | 1500×500 |
| 长文章节图（inline） | 16:9 或 1:1 | 灵活 |

### 不做的事

- ❌ 用 emoji 当主视觉
- ❌ 用渐变、阴影、3D
- ❌ 用暖色（橙黄红系）做大面积背景
- ❌ 在 1 张图里说 2 个观点
- ❌ 放超过 30 字
- ❌ 用网络梗图、二次元图
- ❌ **木刻/铜版画风**（那是 AI 想象出来的，不是 Dan Koe 实际风格）

## Part 2: 写作风格（review / modify 阶段）

> Dan Koe 的写作风格 = **哲学 + 实操双层**。光有哲学 = 鸡汤；光有实操 = 没灵魂。

### 5 个核心模式（来自 AutoTweet.io 风格指南）

#### 1. 现代僧侣式哲学框架（Modern-monk philosophical framing）
- 工作、身份、意义用禅意/冥想式表达
- 高频词：注意力、临在、专注、当下
- 翻译给创客/一人公司语境

#### 2. 一人公司具体性（One-person-business specificity）
- 内容系统 / 粉丝增长 / 变现漏斗的具体框架
- 哲学 + 实操并存
- 例：写"深度工作"不只讲哲学，给具体每周 4 小时分配

#### 3. 身份转换钩子（Identity-shift hooks）—— **最强武器**
- 句式：`Stop being [old identity]. Become [new identity]. The shift: [1-line frame].`
- 不是行动层（"做 X"），是身份层（"成为 X"）
- 例：
  - ❌ "Try writing 1000 words a day"（行动层）
  - ✅ "Stop being a writer. Become a publisher."（身份层）

#### 4. 长结构化线程（Long structural threads）
- 15-25 条推文 / 5-9 段公众号段落
- 结构：引入 → 框架 → 流程 → 应用

#### 5. 日常栈揭示（Daily-stack reveals）
- 早上流程、内容工作流、周节奏
- 流程本身就是内容

### 3-beat 结构（最常用模板）

```
The [modern problem].
The [philosophical reframe].
The [tactical fix].
```

例：
- The AI is replacing your content.（问题）
- The AI is forcing you to find your voice.（哲学重构）
- Ship one idea per day, even if ugly.（实操修复）

### review 阶段打分加成（v2）

如果 modify 阶段选 primary_style = dankoe，按上面 5 个模式检查改稿：
- ✅ 至少 1 个 "identity-shift hook" → +0.5 分
- ✅ "philosophy + tactic" 双层都有 → +0.5 分
- ❌ 全是 action-level 没有 identity-level → -1 分
- ❌ 全鸡汤没实操 → -1 分
