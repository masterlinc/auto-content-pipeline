# 文档风格规范（锁定版）

> **⚠️ 这是固化版本。要改必须跟 linc 确认，不要自动改。**
> 修改后请同步更新 sha256 摘要（在文件底部 `## Style Version` 节）。

## 账号定位

- **平台**：小红书（也兼容公众号）
- **受众**：18-35 岁中国用户，爱看突发新闻、热点、民生、国际局势
- **调性**：信息密度高、有态度、不油腻、不官腔
- **目标**：让用户在 30 秒内 get 到"发生了什么 + 为什么重要"

## 标题套路（10 个模板，按事件选）

| 类型 | 模板 | 例 |
|------|------|----|
| 突发 | `【突发】<事件>！<关键后果>` | 【突发】伊朗对以色列发动导弹袭击！3 名美军阵亡 |
| 速报 | `<事件>，<数字>+<关键>` | 中东房租集体上涨 8%，北上广深无一幸免 |
| 反转 | `<原事件>？<反转>` | 鸿蒙 PC 是套壳？华为官方回应了 |
| 民生 | `<人群>+<数字>+<影响>` | 北上广深打工人 7 月人均多花 1200 元 |
| 国际 | `<地点>+<动作>+<数字>` | 俄乌交换 200 名战俘，最新一批含 12 名外籍雇佣兵 |
| 科技 | `<品牌>+<产品>+<关键词>` | 鸿蒙 PC 正式开放下载！首款国产桌面系统 |
| 娱乐 | `<人物>+<动作>+<悬念>` | 杨幂突然清空微博，工作室回应：家事 |
| 财经 | `<标的>+<涨跌>+<原因>` | 比特币跌破 5.8 万美元，三大利空同时发酵 |
| 社会 | `<地点>+<事件>+<数字>` | 上海地铁 1 号线故障，早高峰延误 40 分钟 |
| 体育 | `<赛事>+<结果>+<关键>` | 世界杯半决赛：阿根廷点球淘汰法国，梅西两度扳平 |

**通用规则**：
- ≤ 28 字（小红书单行显示完整）
- 带 1-2 个 emoji（🔥💥⚡📍💡🎯❗）
- 不带"震惊！""速看！""99% 的人不知道"这类标题党
- 一事件一标题，不堆砌

## 正文结构（4 段式）

```
第 1 段（开篇 1-2 句）：用 emoji + 短句点出"是什么事"
第 2 段（关键信息）：📍 关键信息：+ 3-5 条 bullet
第 3 段（影响/解读）：💡 后续影响 / 解读 / 为什么重要 + 2-3 条 bullet
第 4 段（话题）：3-5 个 #标签
```

### 第 1 段开篇模板

```
🔥 【突发】<事件核心>!

据 <来源> 报道，<具体细节>。
```

或：

```
⚡ <事件核心>！<关键数据>。

<一句话背景或冲突点>。
```

**规则**：
- 必带 emoji 起手
- 第二句必须有具体细节（数字、人名、地点、时间）
- 来源必须可查（"据 BBC 报道""据新华社""微博@xxx""网传，未经证实"）

### 第 2 段：关键信息（bullet）

```
📍 关键信息:
• <事实 1>（数字/时间/人物）
• <事实 2>
• <事实 3>
• <事实 4>（可选）
• <事实 5>（可选）
```

**规则**：
- 3-5 条 bullet
- 每条都要有数字/时间/人物/地点（不要空泛）
- bullet 之间用全角空格或 `•`
- 不要用 emoji bullet 混进关键信息段（emoji bullet 单独段用）

### 第 3 段：影响/解读

**三种结尾，根据事件选**：

**(a) 后续影响类（突发新闻用）**
```
💡 后续影响:
• <对 A 群体的影响>
• <对 B 群体的影响>
• <对市场/行业的影响>（可选）
```

**(b) 解读类（科技/财经用）**
```
💡 为什么重要:
• <关键点 1>
• <关键点 2>
```

**(c) 怎么看类（社会争议用）**
```
💡 网友怎么看:
• "..."（来源）
• "..."（来源）
```

### 第 4 段：话题标签

```
#伊朗 #中东局势 #国际新闻 #突发 #热点
```

**规则**：
- 3-5 个标签
- 前 1-2 个是事件具体词（高流量）
- 后 2-3 个是分类词（长尾流量）
- 不要超过 8 个（小红书折叠）

## Emoji 用法（锁定）

| Emoji | 用途 | 用在哪 |
|-------|------|--------|
| 🔥    | 突发、热门、爆点 | 第 1 段开头 |
| ⚡    | 速报、即时 | 第 1 段开头 |
| 💥    | 大事件、震撼 | 第 1 段开头 |
| 📍    | 关键信息 | 第 2 段开头 |
| 💡    | 解读、影响 | 第 3 段开头 |
| 🎯    | 关键、精准 | 第 3 段偶用 |
| ❗    | 警示、提醒 | 句末/独立 |
| ✨    | 正面、推荐 | 不常用 |
| 💀    | 翻车、震惊 | 娱乐八卦偶用 |

**总量控制**：一篇文章 4-6 个 emoji，不要超过 8 个。

## 长度

- **目标**：400-600 字（不含标签）
- **下限**：300 字（信息密度不够就加 bullet）
- **上限**：800 字（用户耐心极限）
- 字数检查 = 中文字符数（不含 emoji、标点、空白）

## 禁用词（必须避开）

### 营销/标题党
- "震惊！""速看！""99% 的人""不转不是中国人"
- "必看""收藏""转发"
- "小编""我们一起来看"
- "大家好""今天给大家带来"

### 官方腔
- "据悉""日前""近日""有关方面"
- "高度重视""密切关注""深入研究"
- "积极推进""稳步开展""持续优化"

### 模糊词
- "据说""听说""可能""或许"
- "或将""有望""可能即将"

### 低俗/争议
- 详细病状描写
- 详细死亡/血腥描述
- 民族/地域歧视
- 性别对立表述

## 平台适配

### 小红书专属
- 标签必加 `#小红书` 或分类标签（不要写 `#小红书`）
- 第一行必须抓人（首屏信息折叠）
- emoji 必须显眼
- 适当分段（不要一整段）

### 兼容公众号（备选）
- 标题可以更长
- emoji 可以减少
- 不用话题标签
- 来源标注可以放最后
